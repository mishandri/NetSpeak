# Описание релиза 1.1.0

Готовые тексты для GitHub. Скопируйте нужный в поле «Описание»
соответствующего релиза.

---

## Тег `client-v1.1.0`

```
NetSpeak 1.1.0 — клиент

Главное: видео. Камера и показ экрана живут в самом приложении — без
сторонних программ и расширений браузера.

Новое
-----
Камера и показ экрана. Две кнопки в нижней панели. Своя камера видна
в вашей плитке (картинка зеркальная, как в зеркале), показ экрана —
большим окном слева, участники рядом — столбиком справа.

Камера и экран одновременно. Включайте оба: экран пойдёт большим
окном, камера останется в плитке. Выключение одного не трогает другой,
в том числе «Stop sharing» кнопкой самого браузера.

Плитка ХостЭкрана — всегда первая. У кого включён экран, того плитка
стоит наверху правого столбика у всех участников канала.

Экран — один на канал. Второму показывать нельзя: сервер отказывает и
передаёт хозяину просьбу уступить. Пока хозяин показывает, камера у
остальных продолжает работать.

Микрофон при входе выключен. Как и камера: включайте сами, когда
готовы.

Насколько это тяжело для сети
-----------------------------
Камера — до 640 пикселей по ширине, 24 кадра/с, ~500 кбит/с.
Экран — до 960 пикселей, 10 кадров/с, ~900 кбит/с. Аудио — ~48 кбит/с.
Камера и экран сразу — примерно 1,45 Мбит/с на участника; рассчитано
на домашний Wi-Fi.

Файлы
-----
Для Windows — файл .exe из этого релиза: обновлялка подхватит его сама
при следующем запуске. Для Linux — два файла без расширения:
NetSpeak (клиент) и NetSpeakServer (сервер). Скачайте, дайте право на
запуск и запустите; рядом с ними лежат файлы .desktop для меню
приложений — см. docs/ubuntu.md.

Что проверить после обновления
------------------------------
Включите камеру и экран одновременно: у соседа должны появиться и
плитка с камерой, и большой экран. Плитка ХостЭкрана — первой в
столбике. Остановите показ кнопкой браузера: экран гаснет, камера
остаётся.
```

## Тег `server-v1.1.0`

```
NetSpeakServer 1.1.0 — сервер

Серверная часть видео: флаги камеры и монополия показа экрана.

Новое
-----
* У участника появился флаг камеры: плитки с видео у соседей оживают
  только когда сервер подтвердил флаг — дорожка без подтверждения
  не показывается.
* Показ экрана — один на канал. Кто занял первым, тот и показывает,
  остальным уходит отказ с именем хозяина. Повторные просьбы чаще
  раза в 8 секунд глотаются.
* Вход в канал, где экран уже занят: экран у входящего гасит сервер,
  его клиенту уходит подсказка. Камера при этом остаётся.
* Микрофон новых участников выключен: включают сами.

Обновление
----------
Скачается сразу после выхода и встанет в 3:00 ночи — или по кнопке
«Перезапустить» в окне сервера. Переписка (history) и настройки
сохраняются; разговор в момент перезапуска прервётся.

Совместимость: клиенты 1.0.4 работают с этим сервером как раньше —
голос и переписка, просто без видео. И новый клиент со старым сервером
работает. Видео включается в полную силу, когда обновлены обе стороны.

Файлы
-----
Для Windows — файл .exe из этого релиза. Для Linux — файл без
расширения NetSpeakServer; клиент берите из релиза клиента — там же
лежат файлы .desktop для меню приложений.
```
