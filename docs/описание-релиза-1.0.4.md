# Описание релиза 1.0.4

Готовые тексты для GitHub. Скопируйте нужный в поле «Описание»
соответствующего релиза. Сборка под Linux выходит этим же номером:
тег `linux-v1.0.4` — обновлялка Windows ищет свои, `linux-`-префикс
ей безразличен, поэтому обе стороны живут независимо.

---

## Тег `client-v1.0.4`

```
NetSpeak 1.0.4 — клиент

Главное: второй компьютер больше не притворяется тем же человеком,
что и серверная машина. Если NetSpeak стоит на двух компьютерах
и во втором окне каждый раз слетало имя с аватаром — это оно и было.

Что происходило
---------------
На чужом компьютере клиент открывает приложение через маленький
посредник на 127.0.0.1: так браузер считает адрес своим и не
предупреждает о самоподписанном сертификате. Но страница при этом
запрашивала «кто я» у своего адреса — и посредник с вежливым
localhost отвечал данными СЕРВЕРНОЙ машины. Один профиль делили два
компьютера: аватар, выбранный во втором окне, менялся на первом.

Что изменено
------------
Теперь посредник сам отвечает на вопросы «кто я» личностью СВОЕЙ
машины: клиентская и серверная стороны видны как разные люди, а у
сервера есть надежная примета, чтобы не путать чужие запросы со
своими данными профиля.

Проверено вживую: аватар и имя, выбранные в окне клиента, на
серверном компьютере больше не меняют ничего.

Кроме того
----------
- в тёмной теме значения в списках «Микрофон» и «Динамики» больше
  не теряются: светлый ящик теперь только в светлой теме;
- при каждом запуске в журнал пишется строка «кто мы»: машина,
  номер и имя компьютера — совпадения видно сразу.

Что проверить после обновления
------------------------------
На втором компьютере поставьте своё имя с аватаром, закройте окно,
откройте снова — профиль должен остаться. Список участников на
серверном компьютере от действий второго не должен меняться.
```

## Тег `server-v1.0.4`

```
NetSpeak 1.0.4 — сервер

Сервер и клиент на разных компьютерах больше не перепутаны: сервер
отличает запросы, пришедшие через посредник клиента, от собственных,
и отвечает каждому его личностью. Раньше страница у клиента видела
localhost и брала личность сервера — на двух компьютерах работал
один человек.

Интерфейс приложения отдаёт сервер, поэтому обновлять нужно
NetSpeakServer.exe: вместе с ним приедет и новый интерфейс,
клиент при этом обновится сам.

- в тёмной теме значения в списках «Микрофон» и «Динамики» читаются;
- версии клиента и сервера в настройках продолжают сходиться.

Папки settings, user, logs, data, history при обновлении остаются
на месте, переписка не теряется.
```

## Тег `linux-v1.0.4`

Первая проверенная вживую сборка под Ubuntu 22.04+ (GTK + WebKit2GTK,
один бинарник на программу, как на Windows).

```
NetSpeak 1.0.4 — Linux

Первая сборка, проверенная вживую на Ubuntu 22.04 (GNOME, Wayland):
- окно и трей работают, звук и микрофон завелись;
- программа показывает себя по имени: значок в доке и панели берётся
  из .desktop-файла (net.netspeak.*.desktop), а не общая шестерёнка;
- в списках звука значения читаются и в тёмной теме;
- личность: машина клиента и машина сервера — разные люди.

Установка коротко: системные пакеты (GTK, WebKit2GTK, плагины звука
GStreamer) ставятся по docs/ubuntu.md; дальше — папка рядом с
бинарником, в ней разложены .desktop-файлы: по желанию их можно
переложить в меню приложений.

Обновление под Linux выключено: свежая версия качается руками с
релиза. Префикс linux- обновлялку Windows не интересует, и наоборот.
```
