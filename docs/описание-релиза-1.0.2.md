# Описание релиза 1.0.2

Готовые тексты для GitHub. Скопируйте нужный в поле «Описание»
соответствующего релиза.

---

## Тег `client-v1.0.2`

```
NetSpeak 1.0.2 — клиент

Главное: на других компьютерах больше не нужно нажимать
«Дополнительно → Перейти на 192.168.x.x (небезопасно)».

Почему это было. Приложение открывалось прямо по адресу сервера в сети.
Сервер без интернета не может получить настоящий сертификат — только
самоподписанный, — и браузер на каждом чужом компьютере показывал
предупреждение. Каждый раз, при каждом запуске.

Как стало. Клиент открывает приложение через 127.0.0.1 на своём же
компьютере. Для браузера этот адрес свой и доверенный, предупреждения
нет совсем, а разговор с сервером по-прежнему идёт по https. Ничего
нажимать не нужно — ни при первом запуске, ни потом.

Что ещё исправлено в этой версии:
— если сервер выключился или сеть пропала, приложение честно пишет об
  этом, а не висит молча;
— при переходе на другой сервер прежний посредник закрывается и зря не
  занимает порт;
— сигналы связи между участниками (предложение, ответ, кандидаты
  соединения) проходят через посредник полностью. В промежуточной сборке
  этот путь был сломан: человек появлялся в списке, а звук не шёл. Если вы
  встречали именно такое («контакт есть, а звука нет»), это оно.

Если открываете в браузере или заходите с телефона, предупреждение о
сертификате останется: браузер открывает адрес сам, мимо программы. Там
нажать придётся один раз. Так и должно быть — браузеру неоткуда знать,
что сервер в сети свой.

Внимание. Интерфейс приложения хранится на сервере, а не в клиенте.
Поэтому кладите в релиз оба файла: NetSpeakServer.exe и NetSpeak.exe.
```

## Тег `server-v1.0.2`

```
NetSpeak 1.0.2 — сервер

Сама программа сервера в этой версии не менялась. Исправление, ради
которого вышел релиз, живёт в клиенте — см. описание релиза клиента.

Сервер поднят до 1.0.2, чтобы номера совпадали. В настройках у людей
показывается «клиент 1.0.2 · сервер 1.0.1» и подсвечивается жёлтым: это
означает всего лишь, что сервер на главном компьютере не обновлён.

Что стоит учесть:
— интерфейс приложения отдаёт сервер. Обновите NetSpeakServer.exe на
  главном компьютере — вместе с ним приедет и интерфейс;
— папки settings, user, logs, data, history при обновлении остаются на
  месте, переписка не теряется;
— обновление скачивается сразу, а перезапуск — в 3:00 ночи, либо сразу
  по кнопке «Перезапустить».
```
